# ディレクトリ構成

Nuxt4のディレクトリ構成を参考に構成する

- /app
  - /layouts    レイアウトテンプレート
  - /pages      ページのコンテンツ
  - /utils      ユーティリティ。開発したオリジナルJSの格納
  - /assets     stylus、js、画像などの静的ファイル
  - /components  リアクティブなコンポーネント
- /public      静的ファイル
- /dist        publish用のディレクトリ
